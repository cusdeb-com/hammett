## <a name="базовые-экраны"></a> Базовые экраны

## <a name="предпочтительный-тип-данных-для-регистрации-экранов"></a> Предпочтительный тип данных для регистрации экранов

Используйте множества для перечисления экранов в аргументе `states` при создании объекта класса [`Bot`](../api_reference/core/bot.md#hammett.core.bot.Bot). Множества позволяют избегать дубликатов, а с ними и ошибок, связанных с повторной регистрацией экранов.

## <a name="типизация"></a> Типизация

На протяжении всей кодовой базы Hammett используется _аннотация типов_. Это помогает как в разработке самого фреймворка, так и в написании ботов на его основе.

Аннотация типов служит для разработчиков подсказкой, чего от них ожидает Hammett на каждом этапе разработки: какого типа атрибут класса указать, какой тип аргумента передать, какого типа значение вернуть и т.д. Заглядывайте в модули [`hammett.types`](../api_reference/types.md) и [`hammett.widgets.types`](../api_reference/widgets/types.md) для справки.
